# 📊 Meta Ad Performance Dashboard | Power BI

## 📌 Project Overview

The **Meta Ad Performance Dashboard** is an interactive Power BI project designed to analyze advertising campaign performance across Meta platforms.

The dashboard provides insights into impressions, clicks, engagements, purchases, CTR, engagement rate, purchase rate, conversion rate, audience demographics, geographic performance, and engagement trends.

The objective of this project is to transform raw advertising data into meaningful and interactive business insights that can help evaluate campaign performance and support data-driven marketing decisions.

## 🧮 Important Metrics

### Click Through Rate (CTR)

CTR measures the percentage of impressions that generated clicks.

`CTR = Clicks / Impressions × 100`

### Engagement Rate

Measures how effectively advertisements generate audience interaction.

`Engagement Rate = Engagements / Impressions × 100`

### Purchase Rate

Shows the percentage of impressions resulting in purchases.

`Purchase Rate = Purchases / Impressions × 100`

### Conversion Rate

Measures the percentage of clicks that resulted in purchases.

`Conversion Rate = Purchases / Clicks × 100`
